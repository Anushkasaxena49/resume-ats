# 📄 Resume ATS Tracker

## Description
This project analyzes a resume and compares it with a job description to generate an ATS score. It uses keyword matching to evaluate how well the resume fits the job requirements.

---

## Files in Project
- 🐍 main.py → Main program file  
- 📄 resume.txt → Candidate resume data  
- 📄 job.txt → Job description data  

---

## Features
- ATS score calculation  
- Keyword matching between resume and job description  
- Simple text-based analysis  

---

## Tech Stack
- Python
